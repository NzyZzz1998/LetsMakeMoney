# v1.0.2 原型浏览器验证证据

## 验证对象

- 原型入口：`doc/prototypes/v1.0/index.html`
- 页面标题：`LetsMakeMoney v1.0.2 高保真产品原型`
- 验证日期：2026-07-28
- 验证方式：本地 Chromium DevTools Protocol 自动检查与人工截图复核

## 组合验证

共检查 180 个组合：

- DPI：100%、125%、150%
- 主题：浅色、深色
- 业务状态：加载、错误、上班前、工作且休息前、休息中、工作且休息后、下班后、普通休息日、带薪休息、不带薪休息、跨夜班次
- 窗口：迷你视图、今日详情、日历、Wizard 三步、Settings 四个任务页

结果：

- 横向溢出：0
- 纵向溢出：0
- 超出视口：0
- 可见子元素越出窗口：0

机器可读结果见 [browser-validation.json](browser-validation.json)。

## 交互验证

共检查 22 项交互合同，失败 0 项：

- 新用户默认浅色，且不会因首次展示提前写入持久化值。
- 深色主题即时预览，不提前污染已保存配置。
- 有未保存主题时关闭 Settings 会要求确认。
- 放弃更改后恢复上次主题及控件状态。
- 保存成功后持久化深色主题，重载后仍恢复深色。
- 保存失败后所有窗口恢复上次主题，持久化值不变，但保留用户选择的主题草稿。
- 无变化保存反馈正确。
- “今天”、当前选中、手动带薪/不带薪休息可以复合表达。
- 日历键盘焦点可见，ARIA 日期与业务状态完整。
- 跨夜班次使用“本次夜班收入进度”，显示完整 owner date，并在时间线标注“次日”。

## 证据边界

本证据证明 HTML 高保真原型的布局、状态和交互合同，不等同于 Windows 候选包验收。以下项目仍必须在实现后通过真实 Tauri 窗口、Computer Use 或人工补证验证：

- 深色主题在原生窗口显示前恢复，启动过程无闪白。
- 多窗口真实即时同步及保存失败回滚。
- 真实 Windows 100%、125%、150% DPI。
- 迷你窗口整窗拖动、托盘隐藏、恢复和位置持久化。
- Lucide 依赖许可、按需打包和发布包完整性。
