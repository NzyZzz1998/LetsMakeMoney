# 温暖秩序

LetsMakeMoney 的标识不应该高喊“财富”，而应表达一种安静、持续、可以被信任的增长。图形以清晰的几何骨架建立秩序，以一个轻微向前的动作保留生命力。留白不是空缺，而是让小尺寸轮廓仍能呼吸的必要结构。

颜色来自产品本身：深咖啡承担稳定与可信，金币黄只落在最重要的动势上，柔和绿色表达健康节奏。标识不依赖渐变、阴影或复杂材质获得质感，而依靠比例、转角、笔画粗细和色彩面积的反复校准。每个转折都应显得经过耐心推敲。

形式必须先在 16 像素成立，再允许在 256 像素展现细节。应用图标、标题栏、任务栏和单色托盘使用同一套视觉基因，但可以针对光栅尺寸做光学校正。放大版本的丰富不能以牺牲小尺寸辨识为代价。

品牌不绑定人民币符号、桌宠或某一种工资模式。它应当能够承载“时间如何转化为看得见的进度”这一长期命题，并在未来产品扩展后继续成立。最终结果应像一个被反复使用多年仍然自然的工具标识，而不是一次版本更新里的装饰。

整套交付需要体现克制的工艺感：轮廓坚实，比例紧凑，色彩有限，深浅背景和单色模式均经过检查。真正的精致来自每个尺寸都被单独照料，而不是增加更多视觉元素。
