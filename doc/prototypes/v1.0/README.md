# LetsMakeMoney Windows v1.0.7 高保真交互原型

打开 [index.html](index.html) 可评审 v1.0.7 收官完整方案中的 Mini、Workbench、日期调整、按日加班、月度总结、自定义 Combobox 与窗口表面合同。本原型与 [v1.0.7 PRD](../../releases/v1.0.7/prd.md) 和 [需求追踪矩阵](../../releases/v1.0.7/traceability.md) 共同构成开发前事实源。

## 1. 原型定位

- 延续 v1.0 已发布产品的信息架构，不代表 v1.0.7 已实现。
- 顶部评审控制条不属于正式产品，只用于切换窗口、业务状态、日历状态、主题、DPI 和失败注入。
- 产品窗口由可编辑 HTML、CSS 和 JavaScript 组成，不嵌入运行截图。
- 当前公开基线仍为 v1.0.6 Stable；v1.0.7 处于 PRD 待确认阶段。
- 不恢复宠物，不扩展账号、云同步、安装器、自动更新或多平台。

## 2. 评审控制条

| 控件 | 用途 | 验证重点 |
| --- | --- | --- |
| 窗口 | 切换 Mini、Workbench、Wizard、Settings | 窗口入口、退出与状态保持 |
| Mini 停靠 | 模拟悬浮、左侧和右侧隐私收起 | 非金额竖条、展开与找回 |
| 业务状态 | 切换加载、失败、上班前、工作、休息、结束和跨夜 | 阶段文案与边界数据 |
| 日历状态 | 切换官方、估算、加载、过期和失败 | 来源、降级和重试 |
| 月历周数 | 切换五周和六周月份 | 整月与月度总结无滚动 |
| 主题 / DPI | 切换浅色、深色及 100%/125%/150% | 对比度、裁切、溢出和对齐 |
| 长内容 | 注入长金额和长文案 | 固定窗口尺寸稳定性 |
| 模拟写入失败 | 注入设置、日期调整和加班保存失败 | 草稿、旧数据和重试 |

## 3. Mini 与 Workbench 显示事务

1. 从 Mini 打开 Workbench 时，原型记录 Mini 的悬浮/停靠/收起状态并隐藏 Mini。
2. 正常关闭 Workbench 后，Mini 恢复到进入前状态。
3. 模拟 Workbench 打开失败时，Mini 保持原状态，不形成两个窗口都不可见的结果。
4. Mini 的主动隐私收起不是窗口丢失，不触发安全回落。

原型只验证用户可见事务和状态出口。原生窗口 `show/hide/focus` 失败补偿、置顶策略、真实屏幕几何和日志仍需在 Tauri 实现后验证。

## 4. 按日加班记录

- 日历中的“记录加班”打开当前选中业务日期的编辑器。
- 输入支持 `0` 至 `24` 小时、最多两位小数；提交时按最近一分钟换算。
- `0` 或“删除记录”删除该日记录。
- 保存展示录入时的时薪 `1.0×` 快照；后续工资变化不追溯重算历史记录。
- 模拟失败时保留输入和旧记录，显示可读错误并允许重试。
- 成功后更新日期标记和月度加班工时，不在月度总结展示加班收入。

原型数据只存在于当前浏览器会话。正式数据 schema、原子写入、迁移、回滚和诊断合同以 PRD 的 FR-008 为准。

## 5. 月度总结与六周日历

月度总结只展示：

- 计划工时；
- 截至当前业务时间已流逝的计划工时；
- 用户主动记录的加班工时。

这些指标不代表真实考勤。五周和六周切换会使用不同月份样例；六周月份在常用 Workbench 尺寸内同时展示完整日历、总结和图例，不依赖页面滚动。

## 6. 自定义 Combobox

Settings 的休息模式与大小周周型使用同一可访问 Combobox 样件，覆盖：

- 鼠标打开、选择和外部点击关闭；
- `ArrowUp`、`ArrowDown`、`Home`、`End` 导航；
- `Enter` 或空格确认；
- `Escape` 关闭并将焦点还给触发器；
- `Tab` 正常离开；
- 浅色、深色、焦点环、禁用和弹层向上展开。

该样件通过条件门禁后才能替换正式原生 Select；失败时保留现有控件，不阻塞其他需求。

## 7. 条件 Spike

| 条件项 | 原型能证明 | 原型不能证明 |
| --- | --- | --- |
| Mini 自动隐藏状态机 | 可见状态与恢复出口 | 真实拖动事件、随机序列与 Windows 工作区几何 |
| Combobox | 键盘、焦点、主题和弹层结构 | WebView2/读屏器完整兼容性 |
| 窗口单表面 | CSS 圆角、边框和阴影方向 | Tauri 透明窗口四角及三档真实 DPI |
| CSP | 无 | IPC、资源、更新链和所有窗口兼容性 |
| 性能 | DOM 结构基线 | 冷启动、首帧、Bundle 与 WebView 资源阈值 |

条件项未达到 PRD 阈值时必须停止并回退，不能写成已实现或已通过。

- `app.js` JavaScript 语法通过。

- Mini、Workbench、Wizard、Settings、月度总结、加班对话框和两个 Combobox 的必需节点均存在。

### 2026-08-03 交互验证

使用本机 Microsoft Edge 的 Playwright 通道对 `index.html` 执行 34 项交互检查，结果全部通过：

- 加班保存失败保留 `1.25` 小时草稿并显示错误，重试成功后关闭对话框并生成日期标记；
- Combobox 键盘选择、条件字段显示、`Escape` 关闭与焦点归还通过；
- 浅色/深色 × 100%/125%/150% × Mini/Workbench/Wizard/Settings 共 24 组边界检查通过；
- 浏览器控制台错误 `0`，页面异常 `0`。

临时截图仅用于视觉校准，未写入仓库或原型资源。浏览器 DPI 模拟不等于真实 Windows DPI。

## 9. 真实 Windows 开发后门禁

- Windows 11 单显示器是强制验收环境。
- Windows 10 必须取得真实证据，否则收窄公开支持声明。
- 多显示器不进入 v1.0.7 验收或通过声明。
- 真实 100%/125%/150% DPI 必须覆盖六周日历、Combobox 弹层、透明四角、自由拖动与安全回落。
- 必须验证首次置顶、托盘找回、窗口失败补偿、Mini/Workbench 原生事务、位置持久化和脱敏日志。
