# LetsMakeMoney Windows v1.0.3 高保真交互原型

打开 [index.html](index.html) 可检查 v1.0.3 的年度日历覆盖状态，以及 v1.0.2 已确认的阶段呈现、复合日历和浅色/深色双主题回归。

## 1. 原型定位

- 本原型延续 v1.0 的产品结构，不代表整体技术栈或全局状态管理重写。
- 顶部“验证控制条”仅用于切换窗口、业务状态、日历状态、主题、DPI 和长内容，不属于正式产品界面。
- 原型是需求、交互和视觉合同的开发前事实源；真实控件实现仍以 PRD、React/Tauri 代码和桌面验收共同为准。
- 用户可见文案统一使用“休息”；内部 `lunch_*` 配置键继续保留兼容。
- 本轮不重新设计既有界面，只补充官方、估算、过期、加载失败和重试等真实可见状态。

## 2. v1.0.3 年度覆盖状态

验证控制条可切换：

- **官方日历**：数据来自随包提供并通过来源、schema 与 SHA256 校验的年度文件。
- **估算日历**：目标年份尚无内置官方数据，按用户的单休、双休或大小周配置推算；不代表法定放假安排。
- **加载中**：保持页面结构稳定，暂停日期调整。
- **数据过期**：保留同一目标月份最后可信结果，允许查看和重试，暂停新的日期调整。
- **加载失败**：没有可安全保留的目标月份结果，显示失败和重试。

Today 与 Calendar 必须同时展示同一来源。估算年份仍允许日期调整；手动调整优先于估算结果。完整性错误不得伪装成估算。

## 3. 覆盖窗口

- 迷你收入视图；
- 今日详情与今日安排时间线；
- 收入日历与日期复合状态；
- 三步首次配置 Wizard；
- Settings 的收入与作息、日历、窗口与启动、数据与支持；
- 日期调整对话框；
- 放弃修改、恢复默认和更新确认等对话框。

## 4. 业务状态

验证控制条可切换：

- 加载中；
- 暂时无法计算；
- 上班前；
- 工作中且休息未开始；
- 休息中；
- 工作中且休息已结束；
- 下班后；
- 普通休息日；
- 带薪休息；
- 不带薪休息；
- 跨夜班次且归属日期为前一天。

每种状态均同步更新标题、金额说明、工作进度、下一业务边界与今日安排，不使用固定倒计时文案代替业务边界。

## 5. 今日安排

- 时间列、轴线列、内容列采用稳定三列结构；
- 普通日班展示上班、休息开始、恢复工作、下班；
- 跨夜班次带次日标记，并显示完整归属日期；
- 普通休息日、带薪休息和不带薪休息不展示无意义的有效工时；
- 已完成、当前与未开始节点具有不同视觉状态。

## 6. 迷你视图

- 基准尺寸为 `344 × 108`；
- 错误长文案允许安全扩展至 `344 × 120`；
- 不显示无意义的顶部拖动横线；
- 非交互区域均可作为拖动入口，按钮等交互控件属于拖动排除区；
- 覆盖加载、错误、上班前、工作、休息、下班后和休息日状态；
- 长金额与长倒计时不得造成裁切或文本重叠。

## 7. 日历复合状态

日历同时表达：

- 业务状态：普通工作日、普通休息日、官方调休工作日、手动工作日、带薪休息、不带薪休息；
- 导航状态：今天、当前选中日期；
- 交互状态：hover、keyboard focus、disabled、stale。

业务状态使用底色；今天使用日期数字环；选中日期使用单元格边框；手动来源使用角标。今天和选中状态不得覆盖日期本身的业务状态。

## 8. 图标

- 今日、日历、设置、月份切换、关闭、重试和状态入口统一使用 `lucide-react@1.27.0` 对应图标语义；
- 原型用确定性内联 SVG 表达开发目标，不保留文字拼装图标；
- 正式包按需打包，并随包提供 ISC 许可声明；
- 图标加载失败时保留可读文本或原生按钮语义。

## 9. 双主题

- 浅色模式为新用户、旧配置与非法主题值的默认回退；
- 深色模式覆盖 Mini、Workbench、Settings、Wizard、对话框及所有加载、错误、禁用、焦点和日历状态；
- Settings 中选择主题后即时预览；
- 保存成功后持久化并同步全部窗口；
- 取消、关闭或保存失败时恢复已持久化主题；
- 保存失败保留用户草稿，允许修正后重试；
- 不包含系统跟随、定时切换、自定义色、第三种主题、主题导入或主题市场；
- Windows 原生托盘菜单继续使用系统样式。

## 10. DPI 与长内容

- 控制条中的 100%、125%、150% 用于标记当前检查目标；
- 开发验收必须在真实 Windows DPI 环境验证窗口物理尺寸、文字清晰度和拖动命中区；
- 浏览器原型同时以 `deviceScaleFactor` 1、1.25、1.5 检查裁切、重叠和溢出；
- 长内容开关用于检查长金额、长倒计时、跨夜说明和中英文混排稳定性。
