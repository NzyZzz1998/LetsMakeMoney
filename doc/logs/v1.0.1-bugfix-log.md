# LetsMakeMoney Windows v1.0.1 Bugfix Log

## V101-BUG-001 日期调整反馈在刷新后消失

- 严重度：发布阻塞
- 状态：已关闭
- 现象：日期调整实际写入成功，但 CalendarView 刷新导致弹层内反馈立即卸载，用户无法确认结果。
- 根因：反馈状态由短生命周期弹层持有。
- 修复：反馈提升到 CalendarView；成功和无变化关闭弹层，失败保留草稿与弹层。
- 验证：TypeScript 行为测试与真实 GUI 的带薪、不带薪、恢复自动流程通过。

## V101-BUG-002 更新检查误报旧版本

- 严重度：发布阻塞
- 状态：已关闭
- 现象：当前版本 `1.0.1` 时，更新检查将 `1.0` 显示为新版本。
- 根因：更新逻辑只判断版本字符串是否不相等，没有按数字段比较版本顺序。
- 修复：实现数字版本段比较；无效版本返回不可用，不伪报更新。
- 验证：Rust 测试 `update_versions_are_compared_numerically` 通过；真实 GUI 显示“当前已是最新版本”。
