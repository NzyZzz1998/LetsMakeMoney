### 已确认技术决策

1. v1.0.1 是收入、日历、状态和用户信任链的补丁版本，不进行整体 UI 或架构重写。
2. 2025、2026 年中国大陆节假日与调休使用包内离线数据，来源和哈希必须可追溯。
3. 手动日期调整支持工作日、带薪休息、不带薪休息；恢复自动通过删除覆盖项完成。
4. 自动休息日不得再选择带薪或不带薪休息，避免重复覆盖无工资槽位的日期。
5. 旧 `rest_day` 在自动工作日迁移为 `paid_rest`；冗余旧值先备份再清理；未知值拒绝并记录错误。
6. 跨夜班次归属于班次开始日，午夜后仍使用前一 owner date，直到班次结束。
7. 金额使用整数分和累计差分配，保证月末守恒。
8. 前端只在 Rust 权威参数范围内逐秒推进；每 30 秒及关键边界重新同步。
9. 行为级测试必须覆盖真实状态和失败补偿，静态关键字检查只能作为辅助。
10. v1.0 tag、Release、发布包和历史验收结论保持不变，作为回滚基线。

### 技术决策

1. React 只维护草稿、显示状态和权威快照之间的短时插值，业务规则继续由 Rust 定义。
2. 日期调整反馈由 CalendarView 持有，避免重载后反馈丢失。
3. 更新版本按数字段比较，不以字符串不相等代表有更新。
4. 官方日历仅覆盖有可追溯来源的 2025、2026，不猜测 2027。
