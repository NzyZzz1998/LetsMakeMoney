## 关键决策

| 决策 | 背景 | 取舍 | 影响范围 | 后续观察 |
|---|---|---|---|---|
| 采用 Tauri 主线 | 视觉表现是最高优先级 | 接受 Rust/前端双栈 | 全部 v1.0 表面与平台层 | DPI、托盘、WebView2 |
| 不采用 WinUI 3 | 原生样板质感与开发摩擦不符合目标 | 放弃原生 UI 路线 | 技术选型与回退 | 不自动重启该路线 |
| 宠物完整下线 | v1.0 重建产品身份 | 放弃 v0.9 核心差异 | UI、运行时、配置、包 | 只通过历史版本恢复 |
| 大小周不设默认周型 | 用户可能本周处于小周 | 多一步明确确认 | Wizard、Settings、schema、计算 | 验证轮换锚点 |

## M3：迷你收入视图与工作台

- 新增共享 Dashboard 快照模型；原生环境调用 Rust 计算命令，浏览器原型使用同口径降级数据。
- 迷你收入视图每秒刷新金额、状态、进度和剩余有效工时，并提供可拖动区域、加载与错误状态。
- 工作台 Today 接入共享快照；Calendar 增加日期类型和单日手动覆盖交互。
- 为长金额、加载、错误、键盘焦点和日期弹层补充稳定布局与语义。
- Playwright 验证 `344×120` 与 `920×640` 真实视口，日历手动覆盖和键盘入口通过。

## M4：Wizard 与 Settings

- 建立共享配置草稿、字段校验、脏状态、取消恢复、恢复默认和保存反馈模型。
- Wizard 收敛为三步：收入与休息、工作与午休、确认配置；大小周不预选本周类型。
- 上班时间、午休开始和午休时长共同推算午休结束与下班时间，默认有效工时为 8 小时。
- Settings 按收入与作息、日历、窗口与启动、数据与支持四个任务组组织。
- 保存失败保留用户输入和旧配置；Rust 事务测试覆盖临时写入失败与开机启动副作用失败回滚。
- 增加放弃草稿与恢复默认的确认弹层；字段校验失败后聚焦首个错误输入。
- 验证：M4 静态门禁 11/11、Rust 回归 10/10、前端生产构建和三档 DPR 布局检查通过。
