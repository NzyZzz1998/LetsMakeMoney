# LetsMakeMoney v1.0.1 计算说明

## 日历优先级

1. 用户手动调整。
2. 中国大陆法定节假日与调休工作日。
3. 用户配置的单休、双休或大小周。

手动调整支持：

- 工作日：加入当月工资槽位。
- 带薪休息：保留当日工资，不累计有效工时。
- 不带薪休息：当日工资为 0，并降低当月预计应发。
- 恢复自动：删除该日覆盖项，重新按官方日历和休息模式计算。

## 班次归属

- 普通班次归属自然日。
- 当下班时间不晚于上班时间时，班次视为跨夜。
- 午夜后但班次尚未结束时，仍归属到前一日的班次开始日。
- 午休、节假日和手动调整均按班次归属日解析。

## 日薪与月度累计

金额统一使用整数分计算。

设：

- 月薪为 `M` 分。
- 当月工资槽位总数为 `N`。
- 当前槽位序号为 `k`。

累计金额：

`C(k) = floor(M × k / N)`

第 `k` 个工资槽位金额：

`D(k) = C(k) - C(k - 1)`

因此最后一个槽位会吸收分币尾差，完整工作月的累计金额严格等于月薪。

## 秒级收益

- Rust 返回权威阶段、owner date、边界和金额。
- 前端只在有效工作区间按当前秒推进展示。
- 上班前、午休、下班后、带薪休息和不带薪休息停止本地推进。
- 每 30 秒及窗口恢复、阶段边界、日期变化时重新获取权威快照。
- 偏差超过 1 分、阶段或 owner date 不一致时立即校正。

## 数据范围

- 官方日历覆盖 2025、2026。
- 不支持年份会明确提示，不使用猜测数据。
- 本版无数据库影响，配置和离线日历均为本地文件。
