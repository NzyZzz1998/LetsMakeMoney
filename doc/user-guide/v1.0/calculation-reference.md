## 2. 工作日解析

日期解析优先级：

1. 手动覆盖；
2. 调休工作日；
3. 法定节假日；
4. 休息模式。

基础休息模式：

- 双休：周一至周五工作。
- 单休：周一至周六工作。
- 大小周：周一至周五工作；大周的周六工作，小周的周六休息。

大小周使用用户明确选择的锚点周类型，每过一周交替一次。

## 3. 月工作日、日薪与时薪

### 公式

```text
本月工作日 = 当月所有解析为“工作日”的日期数量
日薪（分） = 月薪（分） ÷ 本月工作日，使用整数除法
时薪（分） = 四舍五入（日薪（分） ÷ 每日有效工时）
```

### 示例 A：双休基础演示

输入：

- 月薪：10000 元
- 2026 年 7 月双休基础工作日：23 天
- 每日有效工时：8 小时

手工复算：

```text
月薪 = 1,000,000 分
日薪 = 1,000,000 ÷ 23 = 43,478 分 = 434.78 元
时薪 = round(43,478 ÷ 8) = 5,435 分 = 54.35 元
```

应用在休息日累计截图中显示 23 个本月工作日；此前 18 个工作日累计：

```text
434.78 × 18 = 7,826.04 元
```

实际截图：[休息日今日页](screenshots/raw/LMM-V10-TODAY-001-REST-DAY.png)

### 示例 B：手动把 7 月 26 日改为工作日

覆盖后工作日由 23 天变为 24 天：

```text
日薪 = 1,000,000 ÷ 24 = 41,666 分 = 416.66 元
时薪 = round(41,666 ÷ 8) = 5,208 分 = 52.08 元
```

应用实际显示：

- 今日已赚：¥416.66
- 日薪：¥416.66
- 时薪：¥52.08
- 本月工作日：24 天

实际截图：[工作日完成状态](screenshots/raw/LMM-V10-TODAY-002-WORKDAY-COMPLETED.png)

## 4. 有效工时与今日进度

### 公式

```text
有效工时秒数 = 班次总秒数 - 午休秒数
已完成工时 = 上班至午休开始的已过时间 + 午休结束至下班的已过时间
进度 = 已完成工时 ÷ 有效工时
今日已赚（分） = 四舍五入（日薪（分） × 进度）
```

进度限制在 0%-100%：

- 上班前：0%；
- 工作中：随本地时间每秒增长；
- 午休中：暂停增长；
- 午休后：继续增长；
- 下班后：100%。

演示时间：

```text
08:00-17:00，午休 12:00-13:00
有效工时 = 9 小时 - 1 小时 = 8 小时 = 28,800 秒
```

## 5. 状态判断

| 时间/日期 | 状态 | 收入与进度 |
| --- | --- | --- |
| 休息日 | `rest_day` | 今日收入 0、进度 0，不展示工作卡片 |
| 上班前 | `before_work` | 今日收入 0、进度 0 |
| 上班至午休前 | `working` | 正常增长 |
| 午休区间 | `lunch` | 暂停增长 |
| 午休后至下班 | `working` | 继续增长 |
| 下班后 | `after_work` | 日薪全额、进度 100% |

跨夜班次：当下班时间早于或等于上班时间时，下班、午休端点会按次日计算。午休必须完整落在班次内，否则配置无效。

## 6. 月度累计

```text
本月累计 = 今天之前的工作日数量 × 日薪 + 今日已赚
```

手动调整某一天后，本月工作日和日薪会一起重算，因此月度累计也会变化。

## 7. 显示精度

- 金额：以分计算，界面显示两位小数。
- 时薪：按分四舍五入。
- 今日已赚：按分四舍五入。
- 工作进度：界面显示整数百分比。
- 剩余有效工时：显示 `HH:MM:SS`。
- 页面刷新：运行中每秒更新。

## 9. 当前计算相关限制

- 当前节假日数据只覆盖中国大陆 2026。
- 日历页手动调整目前只保存在 React 会话状态中，没有写入 `date_overrides`，重启后丢失。
- 自动更新查询依赖 GitHub Release；网络失败不影响本地计算。
