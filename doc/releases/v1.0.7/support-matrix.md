# LetsMakeMoney Windows v1.0.7 支持矩阵

## 支持口径

v1.0.7 的“已验证支持”仅表示相应环境取得了真实系统证据，不等同于推断兼容。没有设备证据的环境会明确标记为“未验证”，不会写入通过声明。

| 环境 | 状态 | 本版口径 | 证据或处置 |
| --- | --- | --- | --- |
| Windows 11 x86_64、单显示器、100% DPI | 已验证 | 强制支持环境 | Mini、Workbench、Settings、Wizard、托盘、隐私贴边、窗口找回与双主题已有真实系统证据 |
| Windows 11 x86_64、单显示器、125% DPI | 已验证 | 强制支持环境 | 四窗口、Combobox、六周日历与月度总结已有真实系统证据；首次日历摘要失败修复后通过 |
| Windows 11 x86_64、单显示器、150% DPI | 已验证 | 强制支持环境 | 四窗口、Combobox、六周日历与月度总结已有真实系统证据；首次日历摘要失败修复后通过 |
| Windows 10 x86_64 | 未验证 | 不进入 v1.0.7 已验证支持声明 | 当前没有真实设备或 VM 证据；仅保留尽力兼容，不得写为通过 |
| Windows 11 多显示器 | 暂不验证 | 排除在 v1.0.7 验收与通过声明之外 | 项目所有者已确认本版不覆盖多显示器 |
| 非 x86_64 Windows | 不支持 | 不进入发布包 | 当前只构建 Windows x86_64 |

## 强制功能矩阵

最终候选必须在 Windows 11 单显示器完成：

- 首次启动、配置迁移与恢复；
- Mini 全窗口拖动、自由出屏、松开安全回落、贴边隐私收起与找回；
- Workbench 打开时隐藏 Mini，关闭、失败和取消时恢复进入前状态；
- 今日调整与日历日期调整使用同一事务；
- 加班创建、修改、删除、费率快照和月度汇总；
- 五周与六周月份在常用窗口尺寸下完整显示；
- 自定义 Combobox 的指针、键盘、焦点、Escape、外点击和 ARIA；
- 浅色、深色及 100%、125%、150% DPI；
- 托盘隐藏、恢复、退出与窗口找回。

## 声明边界

- Windows 10 缺少真实证据，因此 README 和发布说明不得使用“Windows 10 已验证”。
- 多显示器不阻塞 v1.0.7，但必须始终标记“暂不验证”，不能由单显示器结果推断。
- 浏览器原型、CSS 缩放和静态几何矩阵不能替代真实 Windows DPI 证据。
- 支持矩阵在候选 EXE、WebView2、窗口参数或 CSS 发生变化后失效，必须重新验证受影响项。
