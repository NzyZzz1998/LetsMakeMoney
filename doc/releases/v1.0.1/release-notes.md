## 版本定位

v1.0.1 是 v1.0 Stable 的可信度修复版本，重点修正日历、日期调整、跨夜班次和金额精度，不扩展产品范围。

## 主要改进

- 内置 2025、2026 年中国大陆法定节假日与调休工作日数据。
- 日期调整支持工作日、带薪休息、不带薪休息和恢复自动。
- 日期调整保存成功后，日历、今日状态、工作日数、工资槽位和月度累计统一重算。
- 日历具备加载、过期、失败、不支持年份和重试状态，不再用旧月份冒充目标月份。
- 夜班跨过午夜后继续归属到班次开始日。
- 工作期间收入按秒显示，并每 30 秒与 Rust 权威快照对齐。
- 金额使用整数分与累计差分配，完整工作月累计严格等于月薪。
- 更新检查改用数字版本比较，避免 `1.0` 被误判为比 `1.0.1` 更新。
- 增加 Rust、TypeScript、配置事务和包内资源行为门禁。

## 兼容与数据

- 配置格式升级到 v7，并兼容迁移旧日期调整。
- 配置继续保存在 `%APPDATA%\io.letsmakemoney.windows\`。
- 所有数据保持本地，不需要账号或云同步。
- v1.0 Stable 的 tag、Release 和便携包继续作为回滚基线。

## 已知边界

- 官方离线日历当前只覆盖 2025、2026；其他年份会明确显示不支持，不猜测节假日。
- Windows 睡眠恢复、手动修改系统时间/时区、连续两小时运行仍列为发布前人工补证。
- 不包含宠物、账号、云同步、主题、安装器或静默更新。

## 回滚

1. 退出 v1.0.1。
2. 备份当前 `%APPDATA%\io.letsmakemoney.windows\config.json`。
3. 恢复升级前的配置备份。
4. 启动保留的 v1.0 Stable 便携包。
