## 待人工补证

### 1. 睡眠与恢复

1. 从最终 Zip 新解压目录启动应用。
2. 在工作时段记录迷你视图金额和系统时间。
3. 让 Windows 睡眠至少 2 分钟。
4. 恢复后立即观察金额、阶段和倒计时。
5. 30 秒后再次观察。
6. 通过标准：恢复后不补算午休或非工作时段，30 秒内与权威快照一致，日志无高频重复纠正。

### 2. 系统时间与时区变化

1. 备份系统时间与时区。
2. 应用运行时将时间调整到上班前、工作中、午休和下班后。
3. 观察阶段、owner date、金额和日历当天状态。
4. 切换时区后恢复原设置。
5. 通过标准：窗口重新显示或 30 秒内完成权威同步，不沿用错误日期或继续错误计费。

### 3. 连续两小时运行

1. 保持迷你视图运行两小时。
2. 期间打开今日、日历和 Settings 各三次。
3. 至少执行一次托盘隐藏与恢复。
4. 观察 CPU、内存、金额、倒计时和日志体积。
5. 通过标准：无崩溃、卡死、持续异常增长或日志刷屏。

### 4. 通知区真实鼠标左键

仅在 Computer Use 无法可靠操作通知区时执行：

1. 左键托盘图标隐藏迷你视图。
2. 再次左键恢复。
3. 确认隐藏期间进程仍在。
4. 读取日志确认 `tray.left_click` 与 `window.hidden/window.shown` 成对出现。

## 记录要求

- 每项只能记录：通过、部分通过、未通过、待人工补证、暂不验证。
- 保存截图、日志时间段和候选哈希。
- 验证完成后恢复系统时间、时区、配置和日志。
