# LetsMakeMoney Windows v1.0.3 发布说明

状态：**最终验收通过，可进入发布收口。**

v1.0.3 是 v1.0.2 Stable 之后的可靠性更新，重点解决跨年度日历可用性、隐藏窗口生命周期和系统时间环境变化后的状态收敛。本版不改变既有收入公式、日期调整事务和双主题口径。

## 主要改进

- 当官方年度日历尚未覆盖目标年份时，按用户配置的单休、双休或大小周继续提供明确标记为“估算”的日历与收入结果。
- 官方数据、估算数据、过期数据和完整性错误使用不同状态，完整性错误不会被伪装成估算。
- 手动工作日、带薪休息、不带薪休息和恢复自动判断继续适用于估算年份，并驱动收入、日历和今日安排同步重算。
- 年度日历改为 manifest 驱动校验，构建和包体验证会核对来源、年份、schema、文件集合与 SHA256。
- 隐藏窗口暂停本地 tick 与权威同步；恢复时立即读取最新配置并执行一次权威同步。
- Windows 隐藏二级窗口时同步挂起其 WebView2，恢复窗口时恢复 WebView2，避免不可见窗口持续占用资源。
- 系统时钟或时区样本变化后重新计算阶段、归属日期、金额与日历，并记录脱敏诊断事件。

## 数据与兼容

- 配置格式和现有收入公式保持兼容。
- 2025—2026 官方离线日历继续作为当前官方数据基线。
- 2027 官方节假日数据尚未发布时不会预置、推测或伪造；界面使用明确的非官方估算。
- 大小周的当前周类型仍由用户指定，应用不会替用户决定。
- 失败的年度数据更新不会覆盖上一份有效官方数据、用户配置或日期调整。

## 已知边界

- 本版不提供在线日历服务或应用内年度数据下载入口；新增官方年份仍通过受控仓库、构建和发布流程完成。
- 原生托盘菜单继续使用 Windows 系统样式。
- 不包含宠物、账号、云同步、安装器、静默更新或跨平台扩展。
- 本版继续使用便携 Zip 分发；不提供安装器。
