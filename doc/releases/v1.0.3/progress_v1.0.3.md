## 版本目标

- 在官方年度数据尚未发布时，以明确标记的休息模式估算保持核心页面可用。
- 严格隔离 unsupported、stale 和完整性失败，保护最后可信数据。
- 建立 manifest 驱动、可验证、可回滚的官方年度数据更新与打包流程。
- 隐藏窗口暂停本地 tick 与权威同步，恢复后立即收敛且不复制 timer。
- 通过真实 Windows 睡眠、系统时间、时区和两小时运行证据证明长期可信度。
- 保持 v1.0.2 的收入、日历、日期调整、跨夜、主题、窗口和配置事务不回退。
