## 发布停止条件

出现以下任一情况时停止发布：

- 睡眠恢复、系统时间跳变或 120 分钟门禁未通过。
- 候选身份变化后沿用旧证据。
- 完整性失败被错误降级为官方或估算数据。
- 隐藏窗口继续产生自身 timer，或恢复产生重复 timer。
- 从脏工作树直接发布。
