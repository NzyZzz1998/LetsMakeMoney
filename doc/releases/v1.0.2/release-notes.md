## 主要改进

- 阶段倒计时按真实业务边界显示距离上班、休息、恢复工作或下班。
- 今日安排使用时间、轴线、内容三列结构，并统一采用“休息”语义。
- 迷你视图移除冗余拖动横线，支持全窗口拖动和状态化窗口尺寸。
- 日历同时表达今天、选中日期、业务日期类型、手动调整和键盘焦点。
- 使用固定版本 Lucide React 统一产品入口图标。
- 调休工作日显示数据来源，跨夜班次明确收入归属日期。
- 新增浅色默认与深色双主题，支持本地保存、即时预览、取消回滚和跨窗口同步。
- 修复启动瞬时误报、二级窗口显示阻塞及配置后 Wizard 复用语义错误。

## 兼容与数据

- 配置格式升级到 v8，旧配置缺少主题字段时默认使用浅色。
- 非法主题值安全回退到浅色，并记录诊断事件。
- 配置继续保存在 `%APPDATA%\io.letsmakemoney.windows\`。
- 所有工资、作息、日期调整和主题数据只保存在本机。
- v1.0.1 Stable 的 tag、Release 和便携包继续作为直接回滚基线。

## 已知边界

- 便携 Zip 内 README 与 CHANGELOG 保留发布源码提交时的候选/收口状态快照；GitHub Release 页面与当前仓库文档为发布后的最终状态事实源，程序和二进制身份不受影响。
- 原生托盘菜单继续采用 Windows 系统样式，不模拟 Web 主题。
- 官方离线日历仍覆盖 2025、2026；其他年份明确显示不支持。
- Windows 睡眠恢复、手动修改系统时间/时区和连续两小时运行保留为非阻塞环境补证。
- 不包含宠物、账号、云同步、安装器、静默更新、系统跟随主题或自定义主题。

## 回滚

1. 退出 v1.0.2。
2. 备份当前 `%APPDATA%\io.letsmakemoney.windows\config.json`。
3. 如需恢复旧配置，使用升级前的兼容备份。
4. 启动保留的 v1.0.1 Stable 便携包。
