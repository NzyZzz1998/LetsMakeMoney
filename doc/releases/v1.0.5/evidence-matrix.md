## 1. 证据级别

| 级别 | 证据 | 可证明范围 |
| --- | --- | --- |
| L0 | HTML 原型 / 静态结构 | 文案、状态、布局候选；不能证明 Tauri 壳 |
| L1 | 自动行为与结构测试 | 状态转换、class/ARIA、几何纯函数、隐私负向规则 |
| L2 | Computer Use 真实候选 | 单机真实窗口、主题、边缘、拖动、找回与截图 |
| L3 | 人工硬件补证 | 125%/150% 系统 DPI、多显示器、负坐标、显示器移除、Win10/11 差异 |

任何 L0/L1 证据都不得替代 L2/L3。矩阵行必须记录候选 SHA；候选变化时对应 L2/L3 行全部失效。

## 5. 每条证据的最小字段

- Evidence ID、FR、候选 Zip/EXE SHA、源码 HEAD。
- OS 版本、系统 DPI、主题、窗口标签、边缘、显示器情境。
- 操作入口、预期、实际、结论词。
- 原始证据外部索引与保留状态；仓库内只放脱敏摘要。
- 配置和用户环境备份/恢复结果。
- 失效条件和重验范围。

允许的结论只有：`通过`、`部分通过`、`未通过`、`待人工补证`、`暂不验证`。
