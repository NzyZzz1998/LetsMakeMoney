# v1.0.4 验收证据目录

本目录保存可进入 Git 的脱敏、可复核证据摘要。原始截图、录屏、完整日志和运行时采样保存在仓库外，并通过后续 evidence index 记录身份、保留状态和失效原因。

## 当前文件

| 文件 | 作用 | 隐私边界 |
| --- | --- | --- |
| `m0-baseline.json` | M0 Git、发布、工具链、继承测试、几何与配置决策 | 不记录用户名、绝对路径、薪资、完整配置或秘密 |

## 共同规则

1. 候选、Release 和测试身份使用 SHA256 或 Git commit 标识。
2. 本机工具来源使用稳定的来源类型与脱敏定位符，不写用户目录。
3. 原始证据丢失时必须标记为 `missing`，不得由后来重构的证据冒充。
4. 每项验证失败必须返回非零退出码。
5. 正式 Acceptance 将在本目录增加候选身份、环境恢复和结论摘要。
