# LetsMakeMoney Windows v1.0.4 最小桌面补证清单

## 目的

本清单只记录无法由纯 TypeScript、Rust 或打包合同可靠证明的真实 Windows 行为。自动门禁通过不等于以下项目已经通过。

## Computer Use

| ID | 场景 | 最小操作 | 通过标准 | 证据 |
| --- | --- | --- | --- | --- |
| V104-CU-001 | Settings 配置事务 | 从候选包打开 Settings，分别执行保存成功、无变化和受控失败；失败后重试 | 失败时草稿仍在、旧配置未污染；重试成功后其他窗口收敛 | 操作前后配置摘要、反馈截图、脱敏日志 |
| V104-CU-002 | Mini/Workbench 显隐生命周期 | 打开两个窗口，分别经应用入口隐藏与恢复 | 隐藏时该窗口停止本地 tick/权威同步；恢复只产生一组 timer 和一次即时同步 | 窗口截图、请求计数、脱敏日志 |
| V104-CU-003 | 新解压候选窗口找回 | 从新目录启动，打开主要窗口后隐藏并恢复 | 运行对象身份不变；窗口可见、可聚焦、无重复窗口 | EXE 哈希、窗口清单、截图 |
| V104-CU-004 | Mini 隐私贴边 | 左右边缘分别完成停靠、自动收起、悬停展开、移开收起和拖离 | 工资信息收起后不可见；交互锁不误收起；拖离恢复 floating | 左右边缘截图或录屏、配置摘要、日志 |

## 必须人工

| ID | 场景 | 原因 | 通过标准 |
| --- | --- | --- | --- |
| V104-MAN-001 | Windows 通知区真实鼠标左键隐藏/恢复 | 通知区命中和系统菜单无法由 DOM 行为测试证明 | 普通模式与对应窗口策略均可找回，进程不退出 |
| V104-MAN-002 | 100%/125%/150% 系统 DPI | 必须观察真实 WebView2 与原生窗口边界 | Mini、Settings、Workbench 无裁切、模糊、错位或不可达隐私标签 |
| V104-MAN-003 | 多显示器与负坐标工作区 | 需要真实多显示器环境 | 左右边缘按目标显示器 work area 收起；显示器移除后安全回落 |

## 自动证据边界

- 生命周期、迟到异步结果、配置事务、同步失败、Runtime command/event 和重复 listener 由 `scripts/verify_architecture.ps1` 直接证明。
- 通知区鼠标行为、系统 DPI 观感和真实多显示器行为不得以源码字符串、HTML 原型或纯几何夹具冒充通过。
- 候选身份变化后，本清单中的候选包相关证据全部失效，必须针对新哈希重做。
