# v1.0.4 新解压桌面冒烟合同

## 目的

验证真实便携 Zip 在新的独立目录启动，主要窗口与通知区找回链路可达，退出后没有残留进程，并且验收前的用户配置和日志得到恢复。

## 自动边界

`scripts/smoke_v104_desktop.ps1` 自动完成：

1. 只接受 `LetsMakeMoney-v1.0.4-windows-x86_64.zip`。
2. 若已有 LetsMakeMoney 进程则拒绝开始，避免候选身份混用。
3. 在受控临时目录解压，只启动新解压目录中的 `LetsMakeMoney.exe`。
4. 备份 `%APPDATA%\io.letsmakemoney.windows`；首次启动模式清除测试副本，结束后按文件内容摘要确认精确恢复。
5. 枚举候选进程的全部可见顶层窗口，检查进程未立即退出且出现首个窗口。
6. 记录 Zip 与 EXE 的文件名、大小和 SHA256，不记录本机路径。
7. 最终清理候选进程和临时解压目录，检查没有残留进程。

非交互模式只能得出进程级 `partial`，不得写为完整桌面通过。

## Computer Use / 人工边界

交互模式依次确认：

1. 首次配置 Wizard 或已有配置 Mini 可见。
2. Mini 能打开今日工作台。
3. 今日工作台能打开 Settings。
4. 能重新打开 Wizard。
5. 从真实 Windows 通知区隐藏并找回 Mini。
6. 从托盘退出后进程结束。

真实通知区鼠标操作、任务栏策略和 DPI 清晰度不得用窗口枚举代替。

## 恢复门禁

- 原配置存在：测试后目录必须恢复。
- 原配置不存在：测试后不得留下配置目录。
- 任何残留 LetsMakeMoney 进程均判定失败。
- 证据输出路径不得位于本轮临时解压目录，避免在清理阶段连同证据删除。
- 恢复失败时脚本返回非零；不得继续发布。
- 原始截图和录屏不进入仓库，按外部证据归档合同登记。
