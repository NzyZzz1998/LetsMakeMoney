# LetsMakeMoney Windows v1.0.8 支持矩阵
## 当前开发口径

本矩阵描述 v1.0.8 的目标与待验证边界，不继承 v1.0.7 的通过结论。候选 EXE、WebView、窗口参数、品牌资产或 CSS 发生变化后，受影响的真实 Windows 证据必须重新取得。

| 环境 | v1.0.8 状态 | 发布口径 |
| --- | --- | --- |
| Windows 11 x86_64、单显示器、100% DPI | 待重新验证 | 发布阻塞环境 |
| Windows 11 x86_64、单显示器、125% DPI | 待重新验证 | 发布阻塞环境 |
| Windows 11 x86_64、单显示器、150% DPI | 待重新验证 | 发布阻塞环境 |
| Windows 10 x86_64 | 未验证 | 不写入已验证支持声明；仅尽力兼容 |
| Windows 11 多显示器 | 暂不验证 | 不进入 v1.0.8 通过声明 |
| 非 x86_64 Windows | 不支持 | 不生成发布包 |

WebView2 Runtime 是运行前提。缺失、损坏或初始化失败时必须给出可理解的系统提示，不能用浏览器 fallback 冒充正式桌面运行。

## 必须重新验证

- Mini、Workbench、Settings、Wizard 的浅色/深色和三档 DPI；
- TimeField、Combobox、窗口单一表面和隐私竖条；
- 加班 v1 迁移、v2 创建/修改/删除、日期联动事务和失败恢复；
- 托盘隐藏/找回、置顶、贴边收起和窗口位置；
- L2 Logo 在标题栏、任务栏、托盘和文件属性中的辨识；
- 候选 Zip、EXE、版本元数据、README 和哈希一致性。
