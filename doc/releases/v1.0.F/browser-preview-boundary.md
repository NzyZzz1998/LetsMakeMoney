# v1.0.F 浏览器预览边界
## 定位

浏览器 fallback 仅用于组件开发、原型交互和无 Tauri 环境下的布局检查。页面固定显示“开发预览 · 收入与日历为非权威模拟数据”，版本身份固定为 `dev-preview`。

## 权威边界

| 能力 | 浏览器预览 | 正式桌面权威来源 |
| --- | --- | --- |
| 收入与阶段展示 | 固定示例算法，只用于渲染 | Tauri/Rust Dashboard domain |
| 日历 | 周末简化推算，只用于渲染 | Rust 官方数据、估算合同和手动调整事务 |
| 配置保存 | 不允许写入正式配置 | Rust 配置事务 |
| 日期调整与加班 | 不允许写入记录 | Rust journal 与 overtime schema v2 |
| 窗口、托盘、更新 | 不具备 | Tauri/Windows 原生能力 |
| 发布验收 | 不可作为通过证据 | 锁定候选包与真实 Windows GUI |

浏览器结果与 Rust 不一致时，以 Rust 为准；测试应报告漂移，不得将 fallback 扩展成第二套权威领域模型。

## 门禁

- 浏览器运行时必须拒绝桌面写命令，并返回稳定的 `desktop_runtime_unavailable:*` 错误。
- 正式桌面窗口不得显示开发预览标识。
- 浏览器截图不得进入候选身份、收入正确性、日历正确性或发布验收证据。
