# LetsMakeMoney Windows v1.0.8 发布说明
> 状态：草案，尚未发布。

## 本版重点

- 完成 v1.0 系列的版本、品牌、候选包和支持边界收口。
- 采用 L2“燕麦石墨”正式 Logo，并统一应用、托盘和窗口品牌入口。
- 加班记录升级为 schema v2：按下一次真实工作开始计算动态上限，支持自然周末改工作日时原子联动。
- 保留加班分钟精度、录入时 1.0× 时薪快照、跨夜 owner date 与历史 v1 读取兼容。
- 完成 TimeField、Combobox、窗口单一表面和 Mini 隐私竖条的生产级收尾。
- 清理陈旧 IPC，建立浏览器预览、证据、品牌资产、脚本生命周期与 v2 债务边界。
- 移除 Windows 启动路径中的重复 WebView2 注册表探测，显著缩短本机冷启动时间。

## 兼容与边界

- 保持 v1.0.7 的工资、日历、主题、托盘和本地数据主合同。
- v1.0.7 可读取历史 schema v1；v1.0.8 提供兼容导出/回退边界，不静默裁剪历史加班。
- Windows 11 x86_64 单显示器为强制验收环境。
- Windows 10 无真实证据时不进入已验证支持声明；多显示器暂不验证。
- 本版不恢复宠物，不加入账号、云同步、安装器、自动更新或多平台。

## 发布附件

正式 Release 只允许：

1. `LetsMakeMoney-v1.0.8-windows-x86_64.zip`
2. `SHA256SUMS.txt`

发布源提交、Tag、Zip、EXE 与 DLL 哈希将在干净候选通过独立验收后填写。
