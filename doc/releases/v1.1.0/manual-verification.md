# LetsMakeMoney Windows v1.1.0 手动验收

所有步骤只能运行从最终 Zip 新解压目录中的 `LetsMakeMoney.exe`。开始前备份 `%APPDATA%\io.letsmakemoney.windows\`，结束后恢复。

## 身份与启动

- [x] 核对 Zip、EXE、WebView2Loader.dll 大小与 SHA256。
- [x] 首次启动默认显示 Mini，不自动启用 Classic。
- [x] 设置切换 Classic 后 Mini 消失；重启后只恢复 Classic。
- [ ] 切回 Mini 后 Classic 被销毁或隐藏，不能同时出现。

## 状态与交互

- [x] working、awake_rest、sleeping 均可辨认并稳定循环。
- [x] 每种基础状态单击 10 次，使用各自反馈并恢复正确状态。
- [x] 长按 500ms 后拖拽 5 次，覆盖左、右和快速反向。
- [x] 释放后完整播放 run_stop；拖拽不误判为单击。
- [x] 拖拽期间窗口失焦/截图会取消活跃输入、完整收势，随后仍可正常单击和再次拖拽。
- [x] 可见像素可交互，透明像素穿透；自动 hit mask 探针与真实 GUI 点击一致。
- [ ] 右键菜单、Settings 和 Modal 打开期间输入锁定，关闭后恢复。

已完成子项：sleeping / working / awake_rest 三基础循环及各自状态反馈连续 10 次通过；5 次 500ms 长按拖拽、左右反向和完整收势通过；右键菜单锁定/释放成对通过。Settings/Modal 组合仍待补证。

已知体验债：idle/基础循环与跑动姿态体量和头部位置不连续，拖拽抓取点视觉上会从头部跳到透明区域；记录为 `V110-UX-001`，不得写成视觉通过。

## 窗口与托盘

- [x] 打开 Workbench 时只隐藏当前陪伴；关闭后恢复进入前模式。
- [ ] Workbench 打开期间切换陪伴模式无死锁、无双窗口。
- [ ] 托盘左键隐藏/恢复、右键菜单和退出符合任务栏策略。
- [ ] 普通隐藏、找回、重启和异常窗口关闭不改变用户选择。

## DPI 与视觉

- [x] 100% DPI：边缘清晰，无蓝边、裁切、比例跳变或脚底漂移。
- [ ] 125% DPI：窗口、动画、命中和拖拽正确。
- [ ] 150% DPI：窗口、动画、命中和拖拽正确。
- [ ] 每次切换 DPI 后重启并确认位置可达；最终恢复用户原 DPI。

## 故障与长期运行

- [ ] manifest 损坏时回落 Mini，收入主线可用且日志说明原因。
- [ ] 图集缺失或哈希错误时回落 Mini，配置不被永久污染。
- [x] 连续观看 30 分钟，无机械高频重复或明显干扰。
- [x] 连续运行两小时，无动画卡死、命中漂移、重复 timer 或异常资源增长。

无法由自动化可靠完成的通知区、DPI 和主观动画观感必须保留真实人工结论，不得用自动门禁替代。
