# LetsMakeMoney Windows v1.1.0 发布说明

## 新增

- Classic 橘猫作为可选桌面陪伴回归，默认仍使用 Mini。
- Mini 与 Classic 严格互斥，Workbench 打开期间统一隐藏当前陪伴。
- 三种基础状态、状态化单击反馈及左右方向长按拖拽。
- 逐帧动画时长、动态透明命中和运行时包损坏回落。

## 兼容与隐私

- config v9 为桌面陪伴增加模式和位置字段；旧配置安全迁移到 Mini。
- Classic 故障不会影响工资、日历、加班、Settings、托盘或更新检查。
- 所有业务数据继续只保存在本机。

## 素材来源

Classic 动画由项目所有者生成、筛选并人工批准，正式包只包含净化运行时图集、命中数据、manifest 和必要来源/许可摘要。生产源文件、失败尝试、Prompt 和 QA 中间文件不进入产品包。相关素材不适用 MIT，具体边界见包内 `ASSETS_LICENSE.md`。

## 延后

本版不开放多多、多宠物、业务事件动作、pointer follow、宠物下载或市场。
