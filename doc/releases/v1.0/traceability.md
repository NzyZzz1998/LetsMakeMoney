## 技术路线决策

| 路线 | 结果 | v1.0 处置 |
|---|---|---|
| Rust + Tauri + React | 推荐并经项目所有者确认 | 唯一实现主线 |
| Godot 4.7 | 可运行但视觉上限不足 | 仅保留 v0.9 回退基线 |
| WinUI 3 | 可构建、可启动，但方向不符合目标 | 淘汰，不作为自动回退 |

## 状态规则

- PRD 是范围事实源。
- 原型是 UI 结构与视觉事实源。
- `dev_plan_v1.0.md` 只能拆解 FR，不得增加产品范围。
- progress 只记录执行状态。
- Acceptance 必须逐项回填 FR 的真实证据。
