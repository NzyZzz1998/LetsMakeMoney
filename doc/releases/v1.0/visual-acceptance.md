# LetsMakeMoney Windows v1.0 视觉手动验收

## 验收目标

本轮只判断 v1.0 Windows 客户端是否达到“清楚、协调、精致、稳定”的视觉要求，不重新评审产品价值，也不扩展功能。发现问题时记录界面、状态、系统缩放和截图，不在验收过程中临时修改程序。

## 验收前准备

1. 退出所有正在运行的 LetsMakeMoney。
2. 将 Zip 解压到一个新的空目录，不覆盖之前的验收目录。
3. 记录解压目录和实际运行的 EXE 路径。
4. 暂时备份 `%APPDATA%\io.letsmakemoney.windows\config.json`。
5. Windows 显示缩放先设置为 `100%`。
6. 截图时保留完整窗口边缘；不要只截局部控件。

建议证据目录：

```text
visual-acceptance/
  100/
  125/
  150/
  states/
  result.md
```

## 一、缩小版 Panel

1. 启动应用并找到迷你收入视图。
2. 确认顶部只有居中的拖动柄，右侧不再显示三点按钮。
3. 检查金额、状态、进度条和时间信息。
4. 在金额较长时再次观察布局，例如 `¥ 12,345.67`。
5. 从顶部拖动柄移动窗口，确认拖动过程中没有闪烁或尺寸变化。
6. 点击收入主体，确认打开今日工作台。

通过标准：

- 四角圆润，阴影自然，没有黑边、白边或额外外框。
- 文字没有截断、重叠、挤压或贴边。
- 金额是第一视觉层级，状态和进度是第二层级。
- 拖动柄可识别但不抢眼。
- 移除三点按钮后，左右留白仍平衡。
- 窗口移动流畅，松开后位置稳定。

建议截图：`mini-default.png`、`mini-long-amount.png`、`mini-moved.png`。

## 二、今日工作台

1. 从迷你收入视图打开今日工作台。
2. 依次切换“今日”和“日历”。
3. 检查今日收益、工作状态、进度、今日安排和月度摘要。
4. 检查日历标题、月份切换、日期网格和图例。
5. 缩窄窗口或使用较长金额，观察布局是否仍稳定。

通过标准：

- 顶部导航、标题、正文和底部区域层级明确。
- 卡片之间留白一致，没有套框感或大面积无意义空洞。
- 今日安排的时间轴、文字和节点对齐。
- 日历每列宽度一致，日期不偏移，图例不拥挤。
- 页面切换时没有明显跳动、闪白或控件位移。

建议截图：`today.png`、`today-long-amount.png`、`calendar.png`。

## 三、首次配置 Wizard

为避免污染现有配置，先移走测试配置，再启动候选 EXE。

逐步检查：

1. 月薪与休息模式。
2. 大小周时，确认必须由用户选择“本周大周”或“本周小周”。
3. 上班时间。
4. 午休开始、午休时长及自动推算结果。
5. 最终确认页。
6. 上一步、下一步、取消和右上角关闭。

通过标准：

- 左侧步骤栏和右侧内容顶部对齐。
- 每一步只突出当前任务，不同时堆出过多输入项。
- 标题、说明、输入控件、推算结果和底部按钮间距均匀。
- 输入框、选择器和按钮高度一致，焦点状态清楚。
- 底部操作栏固定且不遮挡内容。
- 错误状态可读，不造成页面高度突然跳变。

建议截图：`wizard-salary.png`、`wizard-schedule.png`、`wizard-lunch.png`、`wizard-confirm.png`、`wizard-error.png`。

## 四、Settings

依次检查以下任务组：

1. 收入与作息：月薪、休息模式、大小周周型、上下班与午休。
2. 日历：月份规则、手动工作日/休息日调整。
3. 窗口与启动：窗口行为、开机启动及相关反馈。
4. 数据与支持：数据目录、诊断摘要、更新检查与版本信息。

每个任务组都执行：

- 浏览默认状态。
- 修改一个值。
- 保存。
- 再次无变化保存。
- 取消一次未保存修改。
- 关闭并重新打开。

通过标准：

- 顶部任务组切换清楚，不像网页后台标签栏。
- 页面标题、分组标题、设置行和底部反馈层级稳定。
- 控件右侧边界对齐，标签与控件垂直居中。
- 收入与作息中的金额、时间和午休控件不拥挤，长值不挤压标签。
- 没有双横线、重复分隔线或说明文字贴线。
- 保存、无变化、错误反馈位置固定且容易看到。
- 底部按钮不会挤压正文，滚动条不遮挡内容。

建议截图：`settings-income.png`、`settings-calendar.png`、`settings-window.png`、`settings-support.png`、`settings-feedback.png`。

## 五、托盘与窗口状态

1. 使用托盘左键隐藏迷你收入视图。
2. 再次左键恢复。
3. 打开托盘右键菜单。
4. 从托盘打开今日工作台和 Settings。
5. 关闭工作台和 Settings，确认只留下迷你收入视图。

通过标准：

- 托盘菜单文字、行高和分组清楚。
- 恢复后的迷你视图位置和尺寸没有变化。
- 迷你视图不产生任务栏入口。
- 工作台和 Settings 出现任务栏入口，关闭后入口消失。
- 不出现透明空窗口、重复阴影或短暂黑框。

建议截图：`tray-menu.png`、`taskbar-mini.png`、`taskbar-settings.png`。

## 六、三档 DPI

依次将 Windows 显示缩放切换为 `100%`、`125%`、`150%`。每档重新打开并截图：

- 缩小版 Panel。
- 今日工作台的“今日”。
- 日历。
- Wizard 的午休步骤。
- Settings 的收入与作息任务组。

每档通过标准：

- 窗口逻辑比例一致，没有简单位图放大造成的模糊。
- 字体、图标、圆角、阴影和描边清晰。
- 不出现文字裁切、按钮变形、滚动条遮挡或底部区域溢出。
- 相同界面的信息密度没有明显失衡。

完成后将系统缩放恢复到原始值。

## 七、状态与细节

至少检查以下状态：

| 状态 | 重点 |
|---|---|
| 默认 | 视觉层级、对齐、留白 |
| Hover | 颜色变化克制，不引发布局位移 |
| Pressed | 按下反馈明确，不产生夸张缩放 |
| Focus | 键盘焦点清楚，边框不重叠 |
| Disabled | 仍可识别，但不会被误认为可操作 |
| 保存成功 | 反馈清楚且不过度打断 |
| 无变化 | 与成功、失败有明确区别 |
| 保存失败 | 错误可读，输入仍保留 |
| 长内容 | 金额、路径和说明不会破坏布局 |
