## 2. 范围与原则

### 2.1 本次包含

- 无宠物的迷你收入视图、今日/日历工作台、三步 Wizard、四组 Settings 与托盘。
- 框架无关的工资、作息、工作日和日历计算服务。
- v0.9 配置到 v1.0 配置的安全迁移、事务保存、备份和回退。
- Tauri 窗口、托盘、单实例、关闭隐藏、任务栏与数据目录能力。
- 生产级 React 组件、视觉 token、动效、DPI、键盘和可访问性。
- 日志、诊断、恢复、更新检查和便携 Zip。
- 宠物入口、运行时、配置、资源与发布包的安全下线。

### 2.2 本次不包含

- 宠物、动画、多宠物、宠物市场或旧宠物的隐藏入口。
- WinUI 3 实现、Godot 双主线或自动框架回退。
- 主题系统、云同步、账户、多平台、安装器、签名和静默更新。
- 通用财务、考勤、排班、待办或项目计费能力。

### 2.3 实施原则

1. **合同先于界面**：先冻结计算 fixture、配置 schema、日志事件和窗口合同。
2. **新工程与旧基线隔离**：v1.0 Tauri 工程不得边写边删除 v0.9 恢复依据。
3. **同一业务事实源**：Wizard、Settings、迷你视图、今日和日历只消费同一个 Rust domain 快照。
4. **用户明确决策**：大小周必须由用户选择本周是大周还是小周，默认值为 `null`。
5. **真实 Windows 门禁**：125%/150% DPI 与通知区真实左键未通过前，不得宣称平台能力完成。
6. **视觉事实源唯一**：以 `doc/prototypes/v1.0/` 为结构和视觉基线，运行截图只用于对照。
7. **Progress 不记流水账**：实施过程写 dev log，缺陷过程写独立 bugfix log。

## 4. 目标工程边界

建议在现有仓库内新增独立 v1.0 应用目录，实施前由 M0 根据仓库约定确认最终名称。计划边界如下：

```text
apps/windows-v1/
  src/                    React 产品界面
  src/components/         生产级共享组件
  src/features/           mini、workspace、wizard、settings
  src/styles/             token、字体、动效和 DPI 合同
  src-tauri/src/domain/    工资、作息、日历、快照
  src-tauri/src/config/    schema、迁移、事务保存
  src-tauri/src/platform/  窗口、托盘、单实例、系统边界
  src-tauri/src/support/   日志、诊断、更新和恢复
  tests/                   前端、Rust、合同与视觉测试
```

旧 `src/` Godot 代码在 M6 前保持只读恢复基线。不得在新壳尚未通过核心门禁时提前删除。

## 5. 里程碑

### V10-M0 事实冻结、合同与隔离骨架

**目标**：冻结 v0.9 回退身份和 v1.0 的业务、配置、窗口、日志与视觉合同。

**任务重点**：

1. 记录实施起点分支、HEAD、工作区、tag、远端和 v0.9 Release/Zip 哈希。
2. 固化单双休、大小周、午休、夜班、节假日、调休和大金额黄金 fixture。
3. 固化配置 v1.0 schema；`alternating_anchor_week_type` 默认 `null`。
4. 固化配置迁移、备份、失败补偿和 v0.9 回退矩阵。
5. 固化窗口 ID、显示/隐藏、关闭、任务栏和托盘行为合同。
6. 固化日志事件、脱敏字段和验证层级。
7. 建立隔离的 Tauri 工程、依赖锁文件和测试目录。
8. 建立 verification、manual verification 和 release checklist 骨架。

**门禁**：黄金 fixture、schema、回退身份和窗口状态矩阵未落盘，不得开始产品页面迁移。

**回退**：M0 只增加隔离工程、测试与文档；失败时删除未发布的新工程目录，不改 v0.9。

### V10-M1 Tauri 壳、窗口与设计系统

**目标**：建立可启动、可隐藏、可找回且与原型一致的生产级应用壳。

**任务重点**：

1. 锁定 Node、Rust、Tauri、React、TypeScript 和包管理器版本。
2. 实现单实例、迷你窗口、工作台、Settings、Wizard 的窗口注册表。
3. 实现关闭隐藏、窗口复用、任务栏可见性和安全找回骨架。
4. 建立颜色、字体、字号、行高、间距、圆角、阴影、焦点和动效 token。
5. 建立 Button、IconButton、Input、Select、Segmented、Switch、Slider、Toast、Dialog。
6. 建立图标策略、系统字体回退、减少动态效果和键盘焦点合同。
7. 完成空壳在 100%/125%/150% DPI 的布局门禁。

**门禁**：真实 125%/150% DPI 无裁切；窗口关闭、复用和任务栏合同可诊断。

**回退**：保留 Spike 可执行样板；生产壳失败时不进入 M2-M4。

### V10-M2 计算、日历、配置迁移与支持服务

**目标**：建立不依赖 React 的 Rust domain 和可靠本地数据层。

**任务重点**：

1. 实现工作日、日薪、时薪、今日收益和进度计算。
2. 实现单休、双休、大小周及用户指定的本周类型锚点。
3. 实现上班、午休、下班、跨夜与日期归属。
4. 实现节假日、调休和手动覆盖。
5. 实现 v0.9 配置读取、清洗、迁移、原子写入和备份恢复。
6. 实现保存成功、无变化、失败与输入保留所需命令结果。
7. 实现日志轮换、诊断摘要、数据目录、配置恢复和更新查询适配。
8. 用黄金 fixture 和故障注入关闭 domain/config 门禁。

**门禁**：金额误差不超过 0.01；大小周无用户选择时返回明确校验错误；失败写入不污染旧配置。

**回退**：迁移失败保留原配置和备份；新应用显示恢复路径，不覆写 v0.9 数据。

### V10-M3 迷你收入视图与今日/日历工作台

**目标**：交付无宠物后的核心产品表面。

**任务重点**：

1. 实现迷你收入视图的金额、状态、进度、剩余时间和拖动区域。
2. 实现工作台 Today 的收入、今日安排、午休、下班和月度摘要。
3. 实现 Calendar 的工作日、休息日、节假日、调休和手动覆盖。
4. 建立迷你视图与工作台的单向快照刷新和窗口跳转。
5. 覆盖加载、空、配置错误、长金额、长中文和英文。
6. 完成 normal、hover、pressed、focus、disabled、loading、success、error。
7. 完成 Playwright 视觉回归和真实 Windows 截图对照。

**门禁**：与高保真原型的信息层级一致；三档 DPI、长内容和键盘导航无回退。

### V10-M4 三步 Wizard 与任务化 Settings

**目标**：让首次配置和长期维护使用同一草稿、校验和保存事务。

**任务重点**：

1. 建立共享配置草稿、字段校验、脏状态和离开确认。
2. 实现 Wizard 第一步月薪与休息模式。
3. 选择大小周后显示“本周是大周还是小周”，无默认选择，未选禁止下一步。
4. 实现上班、午休时长、午休开始、下班和有效工时推算。
5. 实现确认、上一步、取消、关闭和完成失败恢复。
6. 实现 Settings 四任务组与同一字段组件。
7. 实现保存成功、无变化、失败、恢复默认和注册表补偿。
8. 完成键盘、屏幕阅读器、错误聚焦和三档 DPI 验证。

**门禁**：Wizard 与 Settings 生成同一配置；所有出口都有确定状态、配置和日志证据。

### V10-M5 托盘、窗口生命周期、诊断与更新

**目标**：关闭真实 Windows 平台链路。

**任务重点**：

1. 实现原生托盘菜单和真实左键显示/隐藏。
2. 实现迷你窗口、工作台、Settings、Wizard 的窗口复用。
3. 实现 Explorer 重启、显示器变化和窗口越界回落。
4. 实现任务栏入口、关闭隐藏、退出和进程生命周期。
5. 实现数据目录、诊断摘要、配置恢复和更新检查入口。
6. 实现 WebView2/native 不可用的可读降级。
7. 读取日志验证 tray、window、config、settings、wizard、update 语义事件。

**硬门禁**：必须用真实 Windows 通知区鼠标验证左键隐藏/找回；自动消息不能替代。

### V10-M6 宠物安全下线与迁移收口

**目标**：让 v1.0 活跃源码、配置和发布包中不存在用户可见宠物能力，同时保留历史恢复路径。

**任务重点**：

1. 盘点宠物 UI、autoload、scene、native、资源、配置键、脚本和文档引用。
2. 先断开新 Tauri 主线的宠物入口和依赖。
3. 迁移时忽略旧宠物字段，不因未知值阻塞配置升级。
4. 确认 v1.0 不加载、不复制、不打包宠物资源。
5. 更新许可、第三方声明、README、迁移和回退文档。
6. 仅在新主线门禁通过后清理活跃树冗余；Git 历史和 v0.9 tag 不改。
7. 增加源码和包内“宠物能力数量为 0”检查。

**门禁**：活跃入口、配置输出、运行时加载、发布清单和 Zip 均为 0；v0.9 恢复说明可执行。

### V10-M7 全量回归、Acceptance 与 Stable 发布

**目标**：形成可验收、可回滚、可发布的首个稳定版候选。

**任务重点**：

1. 运行 Rust domain/config/platform 测试。
2. 运行 React 组件、流程与可访问性测试。
3. 运行 Playwright 视觉回归和三档 DPI 截图检查。
4. 实际验证首次启动、Wizard、迷你视图、Today、Calendar、Settings 和托盘。
5. 实际验证保存成功、无变化、失败、配置损坏和 native 降级。
6. 从新解压的便携 Zip 执行真实桌面 Acceptance。
7. 运行公开、许可、UTF-8、文档、包内容和 `git diff --check` 门禁。
8. 更新 verification、manual verification、release checklist、release notes、changelog 和 current。

**通过标准**：`FR-001` 至 `FR-012` 均有自动、日志或真实桌面证据；没有发布阻塞；v0.9 回退身份仍有效。

## 6. 测试与验收

| 层级 | 主要对象 | 通过方式 |
|---|---|---|
| Domain | 工资、日程、日历、大小周 | Rust 单元与黄金 fixture |
| Config | 迁移、原子写入、备份、失败补偿 | 故障注入与文件差异 |
| UI | 组件、Wizard、Settings、工作台 | React 测试与 Playwright |
| Platform | 窗口、托盘、任务栏、单实例 | Rust 集成 + Computer Use |

必须人工或 Computer Use 补证：

- 真实 Windows 125%/150% DPI。
- 通知区真实鼠标左键隐藏与找回。
- 多显示器安全回落（环境具备时）。
- 长时间运行、字体清晰度和动效观感。

## 7. 风险与回退

| 风险 | 触发条件 | 处理与回退 |
|---|---|---|
| Tauri 平台门禁失败 | DPI、托盘或窗口复用不可靠 | 停止完整迁移；回到技术决策，不自动切 WinUI |
| 计算口径漂移 | fixture 与 v0.9/iOS 确认口径不一致 | 阻塞 UI 接入，先修 domain |
| 配置污染 | 迁移或保存失败覆盖旧配置 | 恢复备份，阻塞候选包 |
| 原型落地降质 | 字体、间距、组件或窗口质感明显回退 | 阻塞对应 UI 里程碑 |
| 双栈维护扩大 | Rust 与 React 重复业务规则 | 业务规则回收 Rust，前端只保留展示与草稿 |
| 宠物下线误伤历史 | 修改 tag、Release 或历史恢复材料 | 立即停止，恢复工作树；历史对象只读 |
| WebView2 不可用 | 新环境缺失或启动失败 | 提示安装/修复路径，不静默退出 |
