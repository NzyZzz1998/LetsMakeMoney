# 从 v1.0 回退到 v0.9 Beta

v1.0 不包含宠物功能。需要恢复桌宠体验时，应安装官方 `v0.9-beta` 便携包，而不是把旧宠物文件复制进 v1.0。

## 回退前

1. 从托盘退出 v1.0，确认 `LetsMakeMoney.exe` 已结束。
2. 备份 v1.0 数据目录：`%APPDATA%\io.letsmakemoney.windows\`。
3. 保留 v1.0 首次迁移生成的 `config.v0.9-compatible-backup.<时间>.json`。

## 回退步骤

1. 从 `v0.9-beta` GitHub Release 下载官方 Windows x86_64 便携 Zip。
2. 解压到独立目录，不覆盖 v1.0 目录。
3. 将兼容备份复制为 `%APPDATA%\LetsMakeMoney\config.json`。
4. 从新解压目录启动 v0.9，检查 Panel、桌宠、设置与托盘。

## 不要这样做

- 不要把 v1.0 的 v6 `config.json` 直接覆盖到 v0.9 数据目录。
- 不要把 `assets/pets/`、Godot PCK 或旧 native DLL 注入 v1.0。
- 不要混用 v1.0 与 v0.9 的程序目录。

## 可自动证明与人工边界

- 当前仓库可证明 `v0.9-beta` tag 存在，并包含 Godot 工程、宠物资源和历史回退实现。
- v1.0 迁移测试可证明旧宠物字段不会污染 v6 配置，并会创建兼容备份。
- 在发布签核前仍需使用官方 v0.9 包执行一次真实桌面回退；未执行前不得写成“实际回退通过”。
